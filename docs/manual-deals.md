# 직접 고른 상품으로 deals.json 만들기

2026-10-21부터 쿠팡 자동 갱신(API, goldbox.today 등 외부 경유)을 쓰지 않습니다.
운영자가 쿠팡 파트너스에서 상품을 직접 고르고, 그 링크를 CSV 파일에 적으면 스크립트가 검사한 뒤 `deals.json`으로 바꿔 줍니다.
스크립트는 쿠팡에 접속하지 않습니다. 파일만 읽고 씁니다.

## 순서

1. **파트너스에서 링크 만들기**
   https://partners.coupang.com → 링크 만들기 → 상품을 검색하거나 쿠팡 상품 주소를 붙여 넣고 링크를 만듭니다.
   `https://link.coupang.com/a/...` 모양의 링크를 복사합니다. 그 화면에 보이는 가격도 적어 둡니다.

2. **CSV에 한 줄씩 적기**
   `data/manual-deals.csv`를 엽니다(엑셀, 구글 시트, 메모장 모두 됨). 첫 줄 머리글은 지우지 마세요.
   머리글 아래에 상품 하나당 한 줄씩 적습니다. 어떻게 적는지는 `data/manual-deals.example.csv`를 보세요(예시 상품은 가짜입니다. 그대로 복사하지 마세요).
   엑셀에서 저장할 때는 **CSV UTF-8** 형식으로 저장하세요.

3. **검사만 해 보기**
   ```bash
   node scripts/import-manual-deals.mjs --check
   ```
   `검사 통과: N개 ...`가 나오면 다음 단계로 갑니다. 이 단계에서는 아무 파일도 바뀌지 않습니다.

4. **오류 고치기**
   오류가 있으면 `3행: 가격이 숫자가 아니에요 (지금 값: 만이천원)`처럼 몇 번째 줄이 왜 틀렸는지 전부 보여 줍니다.
   머리글이 1행이고, 첫 상품이 2행입니다. 고친 뒤 3번을 다시 실행합니다. 오류가 하나라도 있으면 `deals.json`은 바뀌지 않습니다.

5. **deals.json 만들기**
   ```bash
   node scripts/import-manual-deals.mjs
   ```
   `deals.json 에 N개 (👶 육아 2개, ...) 썼어요.`가 나오면 끝입니다. CSV에 적은 상품이 기존 `deals.json`을 **통째로 바꿉니다**(예전 상품은 남지 않음).

6. **커밋·배포 전 확인**
   - `python3 -m http.server 8080` → http://localhost:8080 에서 상품 이름·가격·링크가 맞는지 눈으로 봅니다.
   - 링크를 몇 개 눌러 원하는 상품으로 가는지 확인합니다.
   - 필요하면 이어서 품목 페이지를 다시 만듭니다: `node scripts/build-item-pages.mjs`
   - `node --test tests/`가 통과하는지 봅니다.
   - 그다음 `data/manual-deals.csv`와 `deals.json`(그리고 바뀐 파일들)을 함께 커밋합니다.

## 각 열 설명

| 열 | 꼭 적기 | 적는 법 | 예 |
|---|---|---|---|
| 날짜 | 예 | 가격을 확인한 날. `YYYY-MM-DD` | `2026-10-21` |
| 품목 | 예 | `육아` `뷰티` `생활` `반려동물` `패션잡화` 중 하나 | `육아` |
| 상품명 | 예 | 화면에 보일 이름 | `아기 물티슈 100매 10팩` |
| 파트너스링크 | 예 | 파트너스에서 만든 `https://link.coupang.com/...` 링크 | `https://link.coupang.com/a/abc123` |
| 가격(원) | 예 | 지금 판매가. 쉼표·`원`·띄어쓰기는 있어도 됨 | `12,900원` |
| 정상가(원) | 아니요 | 할인 전 가격. 가격보다 작으면 안 됨. **모르면 비워 두세요**(할인율이 안 보임). 지어내지 마세요 | `19,800` |
| 이미지 | 아니요 | `https://`로 시작하는 상품 이미지 주소. 비우면 품목 이모지(👶💄🧺🐶🧦)가 대신 보임 | |

- 같은 파트너스링크는 한 번만 적을 수 있습니다.
- 상품명이나 가격에 쉼표가 들어가면 그 칸을 큰따옴표로 감싸야 합니다: `"12,900원"`. 엑셀·구글 시트로 저장하면 자동으로 감싸 줍니다.
- 이 사이트 화면과 공지 문구에는 대가성 문구("이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.")가 자동으로 붙습니다. 직접 적지 않아도 됩니다.
- ⚠️ 같은 상품을 날마다 새 날짜로 다시 적으면, 가격 기록(품목 페이지 기록 등)에 그날 새로 확인한 것으로 매일 잡힐 수 있습니다. 실제로 그날 가격을 다시 확인한 상품만 그 날짜로 적으세요.

## 자주 나는 오류

| 오류 메시지 | 이유와 고치는 법 |
|---|---|
| `2행: 가격이 숫자가 아니에요 (지금 값: 만이천원)` | 가격은 숫자로: `12000` 또는 `12,000원` |
| `3행: 날짜는 2026-10-21 처럼 실제 있는 날짜로 적어 주세요 (지금 값: 2026-02-30)` | 없는 날짜이거나 `10/21`처럼 다른 모양. `2026-10-21` 모양으로 |
| `4행: 품목은 육아·뷰티·생활·반려동물·패션잡화 중 하나여야 해요` | 다섯 개 중 하나를 글자 그대로 |
| `5행: 파트너스링크는 https://link.coupang.com/ 로 시작하는 주소여야 해요` | 쿠팡 상품 주소(`www.coupang.com/vp/...`)를 그대로 넣은 경우. 파트너스에서 링크를 만들어 넣으세요 |
| `6행: 2행과 같은 파트너스링크예요` | 같은 상품을 두 번 적음. 한 줄을 지우세요 |
| `7행: 정상가(9,000)가 가격(12,900)보다 작아요` | 두 칸을 바꿔 적었는지 확인. 모르면 정상가를 비우세요 |
| `8행: 칸이 머리글보다 많아요` | 쉼표가 든 칸을 큰따옴표로 감싸지 않음 |
| `상품이 한 줄도 없어요` | 머리글만 있고 상품 줄이 없음 |
| `1행(머리글): '가격(원)' 열이 없어요` | 머리글을 지웠거나 바꿈. 예시 파일의 첫 줄을 그대로 복사하세요 |
