# 쿠팡 파트너스와 같이 쓸 제휴 수익처 비교 (핫딜 정적 사이트용)

작성: 2026-10-11 KST · 대상 분야: 출산·육아 소모품 / 1~3만원 뷰티 소모품 / 생활·주방 아이디어 용품 / 반려동물 소모품 / 패션잡화
원칙: 숫자는 출처가 있는 것만 적었고, 출처가 없으면 "확인 못함"으로 표시했어요. "(2차)"는 공식 문서가 아니라 블로그나 기사 출처라는 뜻이에요.

## 결론 요약
| 순위 | 수익처 | 한 줄 이유 |
|---|---|---|
| 기본 | 쿠팡 파트너스 | 5개 분야 모두 커버해요. 24시간 동안 다른 상품을 사도 실적으로 인정돼요. 먼저 15만원 최종승인을 받아야 해요(API도 이때 열려요) |
| 1위 | 링크프라이스 | 개인 가입 가능. 정적 HTML에 딥링크·배너를 그대로 붙이면 돼요. 머천트 한 계정으로 여러 쇼핑몰을 다뤄요. 쇼핑몰마다 Return Day 0~20일(공식) |
| 2위 | 알리익스프레스 어필리에이트 | 개인 가입 가능. 링크 생성 API(`aliexpress.affiliate.link.generate`)가 있어 정적 사이트 자동화에 유리해요. 1~3만원대 아이디어·패션잡화·반려 소품과 잘 맞아요. 요율·쿠키 숫자는 출처마다 달라요 |
| 3위 | 구글 애드센스 | 제휴 링크와 같이 써도 된다고 공식 문서에 명시돼 있어요. 구매가 없어도 노출·클릭 수익이 생겨요. 지급 기준액은 $100(공식). 단, 콘텐츠가 얇은 핫딜 목록 페이지는 승인이 어려울 수 있어요 |
| 조건부 | 네이버 쇼핑 커넥트 | 뷰티·육아 스마트스토어 상품과 궁합이 가장 좋아요. 다만 연동 채널이 네이버 블로그·인스타그램·유튜브라서 **정적 사이트에 링크를 거는 게 허용되는지 확인 못함**. 네이버 블로그를 같이 운영한다면 1~2위급이에요 |
| 비추천 | 테무, 아마존, 텐핑 | 테무: 신규 가입자 첫 구매에만 수수료가 붙고 다단계 논란도 있어요. 아마존: 한국 소비자와 맞지 않아요. 텐핑: CPS 비중이 작고 캠페인마다 조건이 달라요 |

## 1. 플랫폼별 상세

### 1-1. 쿠팡 파트너스 (기준점)
- **수수료**: 별도로 정하지 않은 상품은 3%, 삼성·애플 스마트폰은 1%. 이전 조사(`category-research.md`) 참고
  - 공식 블로그의 운영정책(2020-10-26 적용판)에는 "모든 카테고리 결제금액의 3.00%"라고 적혀 있어요. 오래된 판본이에요. https://coupang-partners.tistory.com/entry/쿠팡-마케팅-제휴-프로그램-운영정책
- **가입**:
  - 쿠팡 회원이면 누구나 가능하고, 개인은 실명 확인만 하면 돼요
  - 사업자는 사업자등록증이 필요해요
  - 미성년자, 비영리법인, 면세사업자는 거절될 수 있어요(공식 운영정책)
- **최종승인**: 누적 판매금액이 15만원을 넘으면 따로 신청하지 않아도 자동으로 검토 대상이 돼요
  - 출처: 쿠팡파트너스 공식 네이버 블로그(2024-09-27) https://blog.naver.com/PostView.naver?blogId=partners_official&logNo=223598482597
  - 15만원 수치는 2차 출처로 확인했어요: https://withzenis.com/쿠팡-파트너스-최종-승인-기준-15만원-달성-및-반려-없는/ , https://coupang.subsidy.kr/coupang-partners
- **API**: 최종승인 후 Access/Secret Key를 발급받을 수 있어요(2차, uup.kr 2026) https://uup.kr/blog/coupang-partners-api-key
- **쿠키**: 접속 시점부터 24시간 동안 발생한 모든 구매가 인정돼요
- **최소 정산**: 1만원 이하이면 다음 달로 이월돼요(공식 운영정책)
- **정적 사이트**: 도메인을 '미디어'로 등록해야 해요. 등록하지 않은 미디어에 광고를 노출하면 금지 행위예요(공식 운영정책 4.1)

### 1-2. 네이버 쇼핑 커넥트 (브랜드 커넥트)
- **수수료**: 판매자가 상품마다 직접 정해요. 공식 문서에는 "상품 별 수수료 n%"라고만 되어 있어요
  - 간접 실적(다른 상품을 본 뒤 24시간 안에 구매)은 기본 1.8%(공식)
  - 판매자 정산기준금액에 비율을 곱해서 계산해요
  - 출처: https://help.naver.com/service/30027/contents/24100 , https://help.naver.com/service/30027/contents/24106 (2026-10 조회)
- **가입**(2차, 2026-04 블로그): https://m.blog.naver.com/windpak07/224241723494
  - 2025-07-23 정식 오픈
  - 네이버 ID에 네이버 블로그·인스타그램·유튜브 중 1개 이상을 연동해야 해요
  - 방문자 수 조건은 없다고 해요
  - 개인 가능(원천세 공제), 사업자는 세금계산서나 현금영수증 필요, 면세사업자는 정산 불가(공식 운영정책)
- **쿠키**: 직접 실적은 링크로 조회한 상품, 간접 실적은 24시간 기준(공식)
  - 2차 출처에는 "유입 후 24시간 이내 + 집계 시점부터 7일 이내"라고도 나와 있어요
- **정산**(공식 운영정책 https://brandconnect.naver.com/service/policy/affiliate/creator):
  - 매월 구매확정분을 다음 달 22일에 확정
  - 23일에 정산 가능 여부를 확인한 뒤 그다음 달 15일에 지급
  - 2차 출처는 "매월 21일 지급"이라고 해서 서로 달라요
  - **최소 정산금액: 확인 못함**
- **API**: 크리에이터용 링크 생성 API는 **확인 못함**
- **궁합**: 뷰티·육아·반려 스마트스토어 상품이 많아서 궁합이 좋아요(정성 평가)
- **주의**:
  - 공식 정책에 "동의 받지 않은 채널로 판매 링크를 발송하는 행위" 금지가 있어요
  - 연동 채널이 블로그·인스타·유튜브 기준이라 독립 정적 사이트에서 써도 되는지는 **확인 못함**. 네이버 고객센터에 문의해야 해요

### 1-3. 알리익스프레스 어필리에이트 (portals.aliexpress.com)

- **궁합**: 어느 쇼핑몰(11번가·G마켓·뷰티몰 등)이 현재 입점해 있는지는 **확인 못함**. 가입 후 머천트 목록을 확인해야 해요

- **출금 주기**: 등급별로 처음엔 월 1회, 고수부터 주 2회(공식) http://tenping.kr/Guide/Benefit

### 1-8. 구글 애드센스 (제휴가 아닌 광고 수익)
- **혼용**: 공식 문서에 "Google 광고와 동일한 사이트 또는 페이지에 Google 이외의 광고를 게재할 수 있습니다. 제휴사나 제한적인 텍스트 링크는 허용됩니다"라고 되어 있어요
  - 단, 인벤토리 가치 정책상 "페이지에 콘텐츠보다 많은 광고를 게재해서는 안 됩니다" https://support.google.com/adsense/answer/9728?hl=ko
- **지급 기준액**: $100(USD 계정 기준, 공식) https://support.google.com/adsense/answer/1709871?hl=ko
- **정적 사이트**: 스크립트 태그만 넣으면 돼요
- **주의**: 광고를 "도움 링크"처럼 위장하면 안 되고, 광고 라벨은 "광고/후원 링크"만 쓸 수 있어요 https://support.google.com/adsense/answer/1346295
  - 상품 링크만 나열한 페이지는 승인 심사에서 불리할 수 있어요(추정, 정량 근거 없음)

## 2. (a) 한 사이트에 여러 제휴 링크를 섞어도 되나?
- **쿠팡 파트너스**: 공식 약관(이용약관·운영정책)에서 **다른 제휴 프로그램 병행을 금지하는 조항은 찾지 못했어요**. 다만 관련 조항이 있어요:
  - 운영정책 4.1-7: "미디어 고유의 콘텐츠보다 쿠팡 파트너스 광고를 포함한 **기타 광고성 콘텐츠의 비중이 압도적으로 큰 경우**" 이용이 제한될 수 있어요. 링크만 모은 핫딜 페이지는 이 조항에 걸릴 위험이 있으니 큐레이션 설명을 꼭 붙여야 해요
  - 등록하지 않은 미디어에 노출 금지 / 클릭 유도 문구 금지 / 쿠팡보다 싸게 살 수 있도록 금품 제공 금지 / 쿠팡 로고·로켓 도형 무단 사용 금지(공식 블로그)

## 4. (c) 한 번에 여러 개 vs 하나로 시작
**하나(쿠팡)로 시작해서 늘리는 걸 추천해요.** 이유:
1. 쿠팡은 누적 판매 15만원이 넘어야 최종승인과 API가 열려요. 판매가 여러 플랫폼으로 나뉘면 이 시점이 늦어지고, 핫딜 자동화에 필요한 쿠팡 API도 늦게 받아요.
2. 플랫폼마다 최소 정산금액이 따로 있어서, 나누면 각 플랫폼에 돈이 묶여요:
   - 쿠팡 1만원 / 링크프라이스 2만원 / 텐핑 5,000원 / 테무 2만원 / 알리 $16에 수수료 $15(2차) / 애드센스 $100 / 네이버 확인 못함
   - 특히 알리는 처리 수수료 때문에, 애드센스는 기준액이 높아서 소액 단계에서는 불리해요.
3. 쿠팡 하나만 써도 24시간 쿠키 덕분에 함께 담는 장바구니 수익을 받을 수 있어요.
- **단계안**:
  - 1단계: 쿠팡만 → 15만원 최종승인 받기
  - 2단계: 링크프라이스 추가(쿠팡에 없는 쇼핑몰 딜이나 가격 비교용)
  - 3단계: 알리 추가(아이디어·잡화 카테고리를 따로 운영, API로 자동화)
  - 4단계: 콘텐츠가 충분히 쌓이면 애드센스 신청
  - 네이버 블로그를 운영하면 쇼핑 커넥트를 블로그 쪽에 별도로 운영
